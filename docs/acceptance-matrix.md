# Acceptance matrix

This matrix separates behavior verified in this workspace from integrations that need external systems. A passing unit test is not treated as proof of a native/store/production integration.

| Phase | Verified here                                                                                                                                                                                                                            | External gate still required                                                                                                                          |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0     | Canonical JSON, config schema, threat model, compatibility/release status                                                                                                                                                                | Official-source recheck before production                                                                                                             |
| 1     | Token scopes/revocation, organizations/projects/RBAC, audit records, idempotent init, doctor, local CLI build                                                                                                                            | Postgres migration rehearsal and real Lynx project/toolchain                                                                                          |
| 2     | Signed manifest, fingerprint, policy verdicts, content hashes, SDK candidate/LKG rollback, delta fallback                                                                                                                                | Android/iOS SDK E2E on devices and object-store presigned flow                                                                                        |
| 3     | Build state machine, queue leases, provider contract, workers, encrypted vault, cache/provenance model                                                                                                                                   | Real isolated Linux/macOS workers, Android/Xcode builds, BYOW security tests                                                                          |
| 4     | Persistent submission job contract and real provider contract tests                                                                                                                                                                      | Live Google Play/App Store Connect sandbox workflows                                                                                                  |
| 5     | Rollout percentage, pause/resume/promote, telemetry aggregation, anti-replay/key revocation                                                                                                                                              | Crash telemetry in native clients and production health automation                                                                                    |
| 6     | Webhooks/signatures/retries, metrics, rate limits, usage ledger/plan policy, runbooks, retention helper, React dashboard client                                                                                                          | Durable observability, backup/restore drill and security scanning                                                                                     |
| 7     | CI workflows, dashboard shell, Compose profile with private Postgres/Redis and external Cloudflare R2 artifact mode, durable adapter wiring, hardened container configuration checks, provider-neutral deployment docs                   | Signed images/SBOM, production backup/restore and worker isolation                                                                                    |
| 8     | Expo config-plugin and LynxView bundle/asset synchronization, ReactLynx/Tailwind fixture, realtime client/banner contracts, notification registration/provider contracts, media picker/camera/audio lifecycle source and Android compile | EAS/macOS iOS build, HarmonyOS host build, real FCM/APNs/Huawei delivery, live backend interoperability, permission/interrupt/codec device validation |

The project must remain Beta until the external gates are executed and recorded with dated evidence.
