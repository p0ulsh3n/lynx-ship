# Feature status

Validation snapshot — 2026-08-30: `pnpm check` passes with 284 tests, all
workspace typechecks, architecture/package-contract checks, lint, package
builds, dashboard build and release-input verification. A real Android Gradle
example build also passes. These results are local evidence; they do not
replace the external iOS, HarmonyOS, device, provider, store or hosted-cloud
acceptance gates listed in `acceptance-matrix.md`.

The current Rspeedy fixtures also build successfully: the basic Lynx template,
the ReactLynx/Tailwind demo and the Android demo all produce non-empty Lynx
bundles; the demos' assets are present in the generated output. This verifies
bundling and staging, not execution on a physical device or a hosted worker.
