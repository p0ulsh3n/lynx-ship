# @lynxship/plugin-api

Public TypeScript contracts for LynxShip project plugins.

The package provides the versioned defineLynxShipPlugin helper and the
declarative contribution types used by lynxship plugin doctor, plugin apply
and native builds. Install it as a development dependency in a plugin package
and declare the entry point under package.json#lynxship.plugin.

See the repository guide at docs/plugin-ecosystem.md for the package
manifest, platform boundaries, security model and release checklist.
