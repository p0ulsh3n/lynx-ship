# @lynxship/ui-tokens

Validates a framework-neutral token map and emits deterministic CSS custom
properties. It is a design-system utility, not a Lynx component library; a
project can consume the output from ReactLynx, Vanilla Lynx, Web, or a host
stylesheet.

The validator rejects circular/deep token groups, duplicate flattened names,
non-finite numbers and CSS delimiter/control characters. `tokensToCss` also
validates the selector so untrusted configuration cannot inject declarations.

## Usage and boundaries

Pass a plain token object to the validator and then to `tokensToCss`; the
resulting names are deterministic and suitable for a stylesheet generated by
the host. Token values are deliberately limited to safe strings and finite
numbers. The package does not provide a component library, theme persistence,
runtime CSS injection, or automatic dark-mode state management.
